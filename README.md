# keepmap

Keep digests and map fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/keepmap/

## Install / run

```bash
git clone https://github.com/theworker02/keepmap.git
cd keepmap
node src/cli.js
node --test
```
